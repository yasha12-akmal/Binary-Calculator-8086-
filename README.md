# 🔢 Binary Calculator (8086 Assembly Language)

## 📌 Overview
This project is a **Binary Calculator** developed using **8086 Assembly Language** as part of the **Computer Organization & Assembly Language (COAL)** course.

It performs arithmetic and logical operations on binary numbers (up to 4 bits) using a menu-driven interface.

---

## 🎯 Objectives
- Understand low-level programming
- Perform binary arithmetic
- Implement logical operations
- Use interrupts (INT 21h, INT 16h)

---

## ⚙️ Tools & Technologies
- Assembly Language (8086)
- MASM / TASM
- DOSBox
- Windows OS

---

## 🚀 Features

### 🔹 Arithmetic Operations
- Addition
- Subtraction
- Multiplication
- Division
- Exponent
- Factorial

### 🔹 Logical Operations
- AND
- OR
- NOT
- 1’s Complement
- 2’s Complement

---

## 🧠 Key Concepts
- Registers & memory handling
- Interrupt-based I/O
- Binary to decimal conversion
- Modular programming using procedures



## ⚠️ Error Handling
- Invalid binary input
- Division by zero
- Wrong menu selection

---

## 🏁 Conclusion
This project demonstrates how low-level programming works using Assembly Language and provides a strong foundation in computer architecture.
